# 自定义桌宠素材放置区

把你自己的桌宠素材放在本目录下，**每个桌宠一个文件夹**（文件夹名即皮肤名）：

```
assets/pets/<你的桌宠名>/
├─ walk.webm     工作中（循环播放）
├─ attack.webm   下达指令/批复发出（单次）
├─ die.webm      等待批复/中断（循环）
├─ special.webm  任务完成庆祝（自动播放 ×3）
├─ sleep.webm    无任务睡觉（循环）
└─ manifest.json 可选：{"name": "...", "title": "显示名称", ...}
```

- 素材格式支持 `.webm` / `.mp4` / `.gif`（纯色背景会自动抠成透明）
- 显示名称 = `manifest.json` 的 `title` 字段（缺省用文件夹名）
- 放好后通过 桌宠右键 → 外观 → 皮肤 或 仪表盘 → 皮肤 选择；首次使用会自动转换

⚠️ 素材版权自负：请使用你拥有权利或已获授权的素材。本目录内容（除本说明文件）不会提交到 git 仓库。
